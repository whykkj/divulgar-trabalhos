# Mao-na-obra

Breve descrição do projeto e qual problema ele resolve.

## 📌 Sobre o projeto

Ele visa a divulgação de pequenas empresas ou de empresas em seu estágio inicial, onde é possível divulgar sua empresa de forma prática.

## 🚀 Tecnologias utilizadas:
-Vue.js
-Tailwind
-JavaScript
-Node.js
-Express
-Sequelize

## Funcionalidades: -Cadastro de usuários/empresas
-Login
-Tela inicial
-Pesquisa
-Categorias
-Especialidades

## 📋 Requisitos de instalação

Antes de iniciar o projeto, é necessário ter instalado:

* Node.js
* npm
* MySQL
* Git

### 🔧 Instalação

-Clone o repositório:

bash
git clone <url-do-repositorio>


-Entre na pasta do projeto:

bash
cd Mao-na-obra


-Instale as dependências:

bash
npm install


-Configure o banco de dados MySQL e as informações de conexão no projeto.

-Inicie o projeto:

bash
npm run dev
